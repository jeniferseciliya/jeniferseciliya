## How I approach analytics

1. Start with the business decision and define the metric precisely.
2. Build a reproducible, tested analytical layer before designing the visual.
3. Communicate the result with context, limitations, and a recommended next action.
4. Use AI to accelerate analysis and documentation while keeping calculations and conclusions reviewable.
